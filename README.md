# Automated Resume Screening Using NLP

## Overview
Automated Resume Screening Using Natural Language Processing (NLP) is a Django-based web application that streamlines the recruitment process by automatically analyzing resumes and identifying suitable candidates based on their skills, qualifications, and profile information.

The system reduces manual screening effort and helps recruiters efficiently shortlist candidates using NLP-based resume analysis techniques.

---

## Features

- User Registration and Login
- Admin Authentication
- Resume Screening and Analysis
- Skill and Keyword Extraction
- Candidate Profile Evaluation
- Recruitment Decision Support
- Database Management using SQLite
- Web-Based User Interface

---

## Technologies Used

- Python
- Django
- Natural Language Processing (NLP)
- SQLite
- HTML
- CSS
- Bootstrap
- JavaScript

---

## Project Architecture

1. User registers and logs into the system.
2. Candidate information is stored in the database.
3. Resume content is processed using NLP techniques.
4. Important skills and keywords are extracted.
5. Candidate profiles are evaluated based on job requirements.
6. Admin reviews screening results.
7. Suitable candidates are shortlisted.

## Installation

Clone the repository:

```bash
git clone https://github.com/ThotakuraJayanth/Automated-Resume-Screening-Using-NLP.git
```

Move to project directory:

```bash
cd Automated-Resume-Screening-Using-NLP
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Apply migrations:

```bash
python manage.py migrate
```

Run server:

```bash
python manage.py runserver
```

Open browser:

```text
http://127.0.0.1:8000/
```
